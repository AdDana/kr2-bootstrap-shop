# Контрольная работа №2: CSS-фреймворки

## Описание проекта
Многостраничный сайт интернет-магазина фигурок «МАГАЗИН ФИГУРОК». Предметная область: продажа коллекционных фигурок (аниме, игры).

## Используемый фреймворк
**Bootstrap 5.3.2**

## Способ подключения
Bootstrap подключен **локально** (без использования CDN). Файлы фреймворка размещены в папке `vendor/bootstrap/`.
Подключение в HTML:
- CSS: `vendor/bootstrap/css/bootstrap.min.css`
- JS: `vendor/bootstrap/js/bootstrap.bundle.min.js`

## Структура проекта
- `index.html` — главная страница;
- `catalog.html` — каталог с фильтрацией;
- `product.html` — страница отдельного товара;
- `order.html` — страница оформления заявки;
- `contacts.html` — контакты;
- `css/custom.css` — кастомные стили поверх Bootstrap;
- `js/main.js` — логика пересчета валют и фильтрации;
- `vendor/bootstrap/` — локальные файлы Bootstrap.

## Реализованные компоненты Bootstrap
- `navbar` (с мобильным бургер-меню);
- `card` (сетка карточек на `row` и `col-*`);
- `btn` (кнопки разных цветов);
- `badge` (статусы товаров: «Предзаказ», «Вышла в релиз»);
- `alert` (информационные плашки);
- `modal` (модальное окно);
- `accordion` (блок FAQ);
- `toast` (всплывающие уведомления);
- Формы: `form-control`, `form-select`, `form-check`, `input-group`.

## Самостоятельные доработки (Дополнительное задание)
1. **Локальное подключение Bootstrap** — фреймворк скачан и подключен из папки `vendor/`.
2. **JavaScript-фильтрация товаров** — на странице каталога реализована клиентская фильтрация по типу фигурок (`complete`, `prize`, `statue`, `nendoroid`) с использованием JS и data-атрибутов.
3. **Адаптивный Triptych-блок** — на главной странице реализован полноэкранный блок с эффектом увеличения картинок при наведении. На мобильных устройствах блок перестраивается в колонку.
4. **Интеграция с API ЦБ РФ** — на всех страницах с товарами реализован автоматический пересчет цен из юаней (CNY) и йен (JPY) в рубли по актуальному курсу. Используется fetch-запрос к `cbr-xml-daily.ru`.
5. **Полноэкранная прокрутка (Scroll Snap)** — на главной странице настроено прилипание секций (`scroll-snap-type`).
6. **Кастомная стилизация** — в `custom.css` переопределены цвета `--bs-primary`, стилизованы кнопки, карточки (добавлен эффект поднятия при наведении) и аккордеон.
